## Assets

Original GLB files are retained in SourceAssets. The supplied models are textured static meshes, without skeletons or animation clips. Converted FBX assets use reduced geometry and the original textures. Character motion is procedural.

## Current implementation assumptions

Keyboard and mouse on Windows; one human versus the computer; selectable character; three-minute matches; two- and three-point shots; overtime for ties. The user was asked about game mode while asset processing continues. These are implementation defaults, not claimed user preferences.

## Visual commitments

The supplied sunset photographs define the setting. A real 3D court, hoops, ball and the supplied characters lead the screen. Traditional Chinese interface. Left, center and right camera presets use the corresponding original photograph as the distant backdrop.
